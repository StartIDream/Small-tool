# 🖱️ 鼠标连点器 v1.3

一个轻量级的 Windows 鼠标连点工具，基于 Python + tkinter 构建，支持多种点击模式和全局快捷键。

## ✨ 功能特性

- **灵活的点击间隔** — 支持 1ms ~ ∞ 的自定义间隔
- **点击次数控制** — 0 为无限循环，正数精确次数自动停止
- **长按模式** — 设置长按时长实现拖拽、蓄力等操作
- **多鼠标按钮** — 支持左键 / 右键 / 中键
- **两种点击位置**
  - 当前位置：鼠标跟随点击
  - 固定坐标：精确点击屏幕指定位置
- **全局快捷键** — 默认 `F6` 开始/停止，支持自定义组合键（`Ctrl+Alt+X` 等）
- **配置自动保存** — 所有设置即时写入 `clicker_config.json`，下次启动自动恢复
- **窗口置顶** — 界面始终可见，方便操作
- **高精度线程控制** — 使用独立线程执行点击，不阻塞界面响应

## 📦 依赖要求

```
Python 3.8+
pydirectinput   # 优先使用（需 DirectInput 支持）
mouse           # 回退方案
```

安装依赖：

```bash
pip install pydirectinput mouse
```

> 程序会自动检测：优先使用 `pydirectinput`，不可用时回退到 `mouse` 库。

## 🚀 快速开始

```bash
python mouse_clicker.py
```

### 使用步骤

1. 设置 **点击间隔**（毫秒，如 100 表示每秒约 10 次点击）
2. 设置 **点击次数**（0 = 无限循环）
3. （可选）设置 **长按时长**（0 = 普通点击）
4. 选择 **点击按钮** 和 **点击位置**
5. 点击 **▶ 开始** 或按下快捷键开始连点
6. 再次点击 / 按快捷键停止

### 快捷键

| 操作 | 默认值 | 说明 |
|------|--------|------|
| 开始/停止 | `F6` | 可在界面自定义，支持 `Ctrl+Alt+X` 等组合 |

**自定义快捷键：**
1. 下拉框选择「自定义」
2. 在右侧输入框内按下想要的组合键
3. 自动识别并注册

## ⚙️ 配置文件

程序启动时会在脚本所在目录生成 `clicker_config.json`：

```json
{
  "interval_ms": 100,
  "hold_sec": 0,
  "click_count": 0,
  "button": "left",
  "hotkey": "F6",
  "mode": "current",
  "fixed_x": 500,
  "fixed_y": 500
}
```

## 🛠️ 打包为 exe

使用 PyInstaller 打包为独立可执行文件：

```bash
pip install pyinstaller
pyinstaller -F -w -n MouseClicker mouse_clicker.py
```

打包后的 exe 会自动在 exe 所在目录读写配置文件。
